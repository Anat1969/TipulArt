# TipulArt

כלי עבודה למטפלת באמנות: ספריית טכניקות וראיות, מתכנן מפגשים, יומן מפגשים עם תמונות יצירה וציר זמן של המטופל/ת.

## שלב נוכחי

גרסה ראשונה חיה: דף בית תלת־ממדי, ספרייה, מפת מטרות, ראיות, מתכנן מפגש, יומן עם תמונות ותצפיות ETC, וציר זמן לכל מטופל/ת.

## קריאה מומלצת

1. `CLAUDE.md`: כללי העבודה לכל שיחה עם Claude Code.
2. `docs/01-spec.md`: מה בונים ולמה.
3. `docs/05-build-prompt-claude-code.md`: פרומפט הביצוע, לפי מילסטונים.

## עקרונות

- האפליקציה אינה מאבחנת. היא מסייעת למטפלת לתעד, לארגן ולחשוב.
- מטופל/ת מזוהה בקוד בלבד. בלי שם, ת.ז. או פרטי קשר.
- עברית ו-RTL בכל הממשק.
- שכבה ויזואלית תלת-ממדית ומונפשת נבנית אחרי שהליבה עובדת.

## הרצה מקומית

```
npm install
npm run dev
```

בדיקה מלאה (Playwright מול build, עם מוקים ל-Supabase):

```
npm run build
npx vite preview --port 4173 &
npm run test:e2e
```

## תשתית

- Supabase: פרויקט cultura-GH, משותף. קידומת `tipul_` לכל הטבלאות, דלי פרטי `tipul-artworks`.
- כניסה: אימייל וסיסמה של חשבון קיים בפרויקט. כפתור Google מופיע אוטומטית אם הספק מופעל.
- פריסה: Vercel, ענף הייצור הוא `main`.
