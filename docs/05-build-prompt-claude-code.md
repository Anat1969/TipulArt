# פרומפט ביצוע ל-Claude Code

העתקה לשיחת Claude Code במאגר `tipulart`.

---

אתה בונה את TipulArt, כלי עבודה למטפלת באמנות (ענת). המשתמשת כרגע היא מטפלת אחת. המודל מוכן לשדרוג לכמה מטפלות.

## לפני כל דבר
1. קרא את `CLAUDE.md`, `README.md`, ואת כל תיקיית `docs/` לפי הסדר: `01`, `02`, `03`, `04`, `06`, `07`.
2. הרץ `uipro init --ai claude`.
3. פתח את הסקיל `end-to-end-builder` ועבוד לפיו.
4. אם יש סתירה בין המסמכים: עצור רק אם היא משנה את המבנה. אחרת, בחר את הגרסה המחמירה יותר והצג הנחה בשורה אחת.

## כללים
- עברית ו-RTL בכל הממשק. ללא אייקונים, חוץ מאייקון האפליקציה.
- סרגל ניווט עליון קבוע בכל דף, כולל הכפתורים שמפורטים ב-`CLAUDE.md`.
- לא לשאול שאלות שאפשר להכריע לבד. להכריע, לציין הנחה, להמשיך.
- לא לשמור שמות, ת.ז. או פרטי קשר של מטופלים. רק קוד.
- לא לבנות אבחון אוטומטי ולא פרשנות AI של ציורים.

## מילסטונים

**M1: תשתית ואבטחה**
- אתחול פרויקט Vite + React + TypeScript, עם PWA בסיסי להתקנה מ-Chrome.
- חיבור ל-Supabase. לפני יצירת טבלאות: `list_projects` לאימות CULTURA-GH. אם לא קיים או לא מתאים, להציע יצירה חדשה.
- יצירת הטבלאות לפי `docs/02-data-model.md`, כולל RLS מלא.
- הרצת `get_advisors` ותיקון אזהרות.
- התחברות אישית (אימייל + סיסמה דרך Supabase Auth).

**M2: ספריית טכניקות ותרגול**
- טעינת הזרע מ-`docs/03-techniques-library.md`.
- דף ספרייה עם חיפוש וסינון לפי אוכלוסייה, מטרה ורמת ETC.
- דף טכניקה עם רמת ראיות וקישור למקור.
- דף תרגיל עם אפשרות סימון "תרגלתי".

**M3: מתכנן מפגש ויומן**
- מתכנן מפגש: בחירת מטופל/ת לפי קוד, בחירת טכניקה, יצירת תוכנית.
- יומן מפגש: העלאת תמונה (עם דחיסה בצד הלקוח), טופס תצפית לפי ETC, הערות.
- ציר זמן לכל מטופל/ת לפי קוד.

**M4: שכבה ויזואלית**
- לפי `docs/04-visual-direction.md`: סצנת 3D בדף הבית, אנימציית מפגש, ציר זמן אנימטיבי.
- כיבוד `prefers-reduced-motion` ותצוגה סטטית בנייד.

## מסירה
- אחרי כל מילסטון: PR ל-`main`, בדיקה ירוקה, מיזוג.
- בסיום כל מילסטון: עדכון `CLAUDE.md` אם למדת משהו שחשוב לשיחות הבאות.
- בסיום הכול: כתובת סופית ושורה אחת.
